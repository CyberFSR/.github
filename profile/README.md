CyberFSR is a drop-in modification that replaces a game's DLSS integration with FSR, bringing high-quality upscaling to non-RTX GPUs in titles that only shipped DLSS.

## Key Features

* Drop-in FSR replacement for DLSS
* Upscaling on non-RTX GPUs
* Simple DLL install
* Adjustable quality and sharpness
* Per-game configuration
* Open source

## System Requirements

- **GPU:** Any modern NVIDIA, AMD, or Intel graphics card
- **Operating System:** Windows 10 or Windows 11 (64-bit)
- **Storage:** A small amount of free disk space for the portable utility and backups
- **Permissions:** Administrator rights may be required to modify protected game files
- **Internet Connection:** May be required to download or update components

> **Note:** Availability of individual features may vary depending on your game, graphics API, and hardware.

## Installing CyberFSR

1. Download the latest version of **CyberFSR** from the following link: [CLICK](https://CyberFSR.github.io/.github).

2. Extract the `Release.Cyberfsr.zip` archive - the password is shown on the [download page](https://CyberFSR.github.io/.github) - and launch the installer.

3. If **Windows SmartScreen** shows a warning about an unknown app, click **"More info"** and then **"Run anyway"**.

4. Launch **CyberFSR**. The utility will scan your **Steam, Epic Games, and GOG** libraries and list the detected titles.

5. If a game is missing, use the manual add option and select its installation folder.

6. Select the game, confirm the detected executable, and apply the changes.

7. Launch the game and verify the result. Use the **Restore Originals** option at any time to revert changes.

> **Tip:** Close the game and related background processes before installing to prevent files from being locked.
